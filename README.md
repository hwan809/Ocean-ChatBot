## 프로젝트 소개

**한바다**는 2024년 제7회 Ocean ICT 행사 기간 동안 실제 운영된 챗봇입니다. 참가팀 포스터 PDF와 엑셀 메타데이터를 전처리하여 벡터 DB에 적재한 뒤, 자연어 질문에 대해 관련 팀 정보를 검색하고 답변합니다. 행사장 지도 위에 부스 위치를 렌더링하는 길 안내 기능도 제공합니다.

## 주요 기능

### 🔍 하이브리드 검색 (Ensemble Retriever)

SelfQueryRetriever가 팀 코드, 팀원 이름, 학번, 분야(물리/화학/생물/지구과학) 등의 **구조화된 메타데이터**를 필터링하고, VectorRetriever가 포스터 본문에 대한 **의미 유사도 검색**을 수행합니다. 두 결과를 0.5:0.5 가중치의 EnsembleRetriever로 결합하여 MMR 기반 상위 10건을 반환합니다.

### 📅 연도 기반 DB 라우팅

GPT-4o가 질문에서 시점을 추출합니다. "재작년에 어떤 팀이 나왔어?"라고 물으면 2022년 DB로, 기본 질문은 2024년 DB로 라우팅합니다. 이를 통해 2019~2024년 6개 연도의 데이터를 하나의 인터페이스에서 검색할 수 있습니다.

### 🗺️ 부스 위치 안내 (OpenCV 지도 렌더링)

팀 코드를 행사장 좌표계로 매핑하여, 입구에서 해당 부스까지의 경로를 지도 위에 렌더링합니다. 화살표와 핀 마커로 정확한 위치를 표시합니다.

### 🎬 팀 소개 영상 연동

답변에 포함된 팀의 YouTube 발표 영상을 채팅 인터페이스에 바로 임베드합니다.

### 📊 QA 로깅

모든 질문-답변 쌍을 타임스탬프와 함께 Google Sheets에 자동 기록하여 운영 분석에 활용합니다.

## 데이터 전처리

| 원본 데이터 | 처리 방식 |
|---|---|
| 참가팀 포스터 PDF (2019~2024) | PyMuPDF로 텍스트 추출 → `page_content`로 분리 |
| 참가팀 엑셀/CSV | 팀 코드, 팀명, 팀원, 주제, 분야 → `metadata`로 구조화 |
| 행사장 배치도 | 팀 코드 → (열, 위치, 방향) 좌표계로 매핑 |

<br>

## 기술 스택

| 분류 | 기술 |
|---|---|
| LLM | GPT-4o |
| 프레임워크 | LangChain |
| 벡터 DB | Chroma |
| 검색 | SelfQueryRetriever + EnsembleRetriever (MMR) |
| 문서 처리 | PyMuPDF |
| 이미지 처리 | OpenCV |
| 프론트엔드 | Streamlit |
| 로깅 | Google Sheets API |
